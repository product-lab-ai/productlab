Does comparing attempts help explain a repair?

These are three working builds of the existing Workings product. Try the same agent lesson in each. The course, tasks, and grading rules are the same.

  • Open current Workings

    The existing experience, copied with its current local changes.

  • Open the retained-attempt version

    Keep the previous program and trace available while you edit and run again.

  • Open the guided-comparison version

    Inspect changed blocks, recorded outcomes, and the first differing event.

Try one complete repair

  1. Open the lesson and follow the working example.
  2. Reach step 4, “Give the next call the missing information.”
  3. Predict and run the starting program. Inspect what happened.
  4. Change result handling, make a new prediction, and run again.
  5. Explain which event changed and how that affected the next model call. Use the comparison button when it is available.

Give feedback

Tell the builder which version made the explanation easier, where you had to stop and think, and whether the comparison revealed too much or added clutter.

This review can guide the next design choice. Repeating the same task also adds practice, so this comparison alone cannot establish a learning gain. A fresh learner task remains separate.
